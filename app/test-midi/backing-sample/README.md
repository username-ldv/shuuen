# Backing-track sample: A Cruel Angel's Thesis (TV size)

A real-song test pair for the Melodies backing-track feature:

- `cruel-angels-thesis-tv-melody.mid` — the sung intro plus the synth hook (46 notes), with
  the recording's real tempo map (80 BPM intro → 128.64 BPM body). Generated by
  `build_melody.py` (see provenance below). The source transcription turns into a piano
  arrangement (not the vocal line) after the hook, so the sample ends there; the rest of the
  data is kept in the script should the later sections ever get a vocal re-transcription.
- **`audio.mp3` — not included, download it yourself** (copyright): it is the audio of the
  ranked osu! beatmap set [Yoko Takahashi - Zankoku na Tenshi no These <TV.Size Version>
  (set 672960)](https://osu.ppy.sh/beatmapsets/672960). Download the `.osz` with your osu!
  account (or any beatmap mirror), rename it to `.zip`, extract `audio.mp3` into this folder.
  Keep it out of git.

The MIDI is timed against **that exact mp3**. A different rip (e.g. from YouTube) will have a
different lead-in and possibly a different master — other TV-size maps float around at
128.84 BPM — so with any other file expect to fix the offset, or drift.

## Level setup in the app

1. Training → Melodies → new level → source mode **Load .midi file** →
   `cruel-angels-thesis-tv-melody.mid`.
2. **Load backing track** → `audio.mp3`.
3. **Audio offset**: `997` ms (where the MIDI's time zero sits in the mp3).
4. In Settings → Sound: turn *Backing track volume* well down (a mastered recording is far
   louder than the MIDI instruments; the slider applies live during playback). *Backing
   track replaces melody* plays only the real recording while the quiz follows the MIDI.

## Structure

| MIDI position | Song section |
|---|---|
| 0:00 | slow intro, "Zankoku na tenshi no yō ni…" (80 BPM) |
| 0:13 | band hook — the synth lead quotes the intro melody (128.64 BPM) |
| 0:21 | melody ends; the recording plays on into the verse |

## Provenance / how the timing was derived

- Pitch sequence: [Online Sequencer transcription 76666](https://onlinesequencer.net/76666)
  (lead instrument, top note per onset; sung sections dropped one octave).
- Timing anchors: the ranked map's `.osu` timing points — 997 ms @ 750 ms/beat, then
  13934 ms @ 466.41791 ms/beat (bar grid from 14867 ms), chorus kiai at 67105 ms with the
  vocal pickup at 66989 ms (= the map's preview time), last object 88910 ms. The generator
  script asserts all of these to ±1 ms.

song) — private test use only; don't redistribute them with the app.
